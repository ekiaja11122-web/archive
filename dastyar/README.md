# دستیار شخصی

یک برنامهٔ شخصی که روی **Cloudflare** اجرا می‌شود و از هر جا — گوشی، تبلت، رایانه —
با یک نشانی اینترنتی در دسترس است. سه کار اصلی برایتان انجام می‌دهد:

| بخش | چه کاری می‌کند |
|---|---|
| **کارها و یادآوری‌ها** | کارهای روزانه، هفتگی و تکرارشونده؛ هر روز صبح یادآوری روی گوشی |
| **گاوصندوق** | رمزها، رمز کارت‌ها، شمارهٔ حساب و مدارک — رمزگذاری‌شده و با جست‌وجوی سریع |
| **حساب و کتاب** | بدهی و طلب، اقساط، واریزهای دوره‌ای و گزارش ماهانه |

به‌علاوه: یادداشت‌ها، دفترچهٔ مخاطبین، تاریخ‌های مهم (تولد، بیمه، چک) و پشتیبان‌گیری.

همه‌چیز فارسی و با **تقویم شمسی** است.

---

## راه‌اندازی — یک‌بار برای همیشه

### پیش‌نیازها
- یک حساب رایگان در [cloudflare.com](https://dash.cloudflare.com/sign-up)
- برنامهٔ [Node.js](https://nodejs.org) نسخهٔ ۲۰ یا بالاتر روی رایانه

### گام‌ها

در پوشهٔ `dastyar` این دستورها را به ترتیب اجرا کنید:

```bash
npm install          # نصب ابزار انتشار
npx wrangler login   # ورود به حساب کلادفلر (مرورگر باز می‌شود)
npm run setup        # ساخت پایگاه داده + انتشار برنامه
```

دستور آخر همهٔ کارها را خودش انجام می‌دهد و در پایان **نشانی برنامه** را نشان می‌دهد؛
چیزی شبیه:

```
https://dastyar.نام-حساب-شما.workers.dev
```

> اگر ترجیح می‌دهید مرحله‌به‌مرحله پیش بروید:
> ```bash
> npx wrangler d1 create dastyar-db     # شناسهٔ خروجی را در wrangler.toml بگذارید
> npm run db:init                        # ساخت جدول‌ها
> npm run deploy                         # انتشار
> ```

### نصب روی گوشی

۱. نشانی برنامه را در مرورگر گوشی باز کنید
۲. **رمز اصلی** بسازید (پایین‌تر توضیح داده شده)
۳. برنامه را به صفحهٔ اصلی اضافه کنید:
   - **اندروید (کروم):** منوی سه‌نقطه ← «افزودن به صفحهٔ اصلی»
   - **آیفون (سافاری):** دکمهٔ اشتراک‌گذاری ← «Add to Home Screen»
۴. از داخل برنامه: **بیشتر ← تنظیمات ← فعال‌سازی روی این دستگاه** تا نوتیفیکیشن‌ها بیایند

> روی آیفون، نوتیفیکیشن فقط وقتی کار می‌کند که برنامه به صفحهٔ اصلی اضافه شده باشد
> (نه در خود مرورگر). این محدودیت از طرف اپل است.

## رمز اصلی — مهم‌ترین نکته

هنگام اولین ورود یک **رمز اصلی** انتخاب می‌کنید. این رمز دو کار می‌کند:

۱. **ورود به برنامه**
۲. **کلید رمزگذاری گاوصندوق**

رمز شما هرگز به سرور فرستاده نمی‌شود. مرورگر از روی آن دو کلید جداگانه می‌سازد:
یکی برای اثبات هویت (که فقط چکیده‌اش روی سرور می‌ماند) و یکی برای رمزگذاری
که **از گوشی شما خارج نمی‌شود**.

یعنی اگر کسی به پایگاه دادهٔ کلادفلر هم دسترسی پیدا کند، فقط متن نامفهوم می‌بیند.

> ⚠️ **اگر رمز اصلی را فراموش کنید، اطلاعات گاوصندوق قابل بازیابی نیست.**
> جایی امن (مثلاً روی کاغذ، داخل گاوصندوق واقعی) یادداشتش کنید.

برای راحتی می‌توانید گزینهٔ «روی این دستگاه به خاطر بسپار» را بزنید تا هر بار
رمز نخواهد. با «قفل کردن گاوصندوق» در تنظیمات، این حافظه پاک می‌شود.

## راهنمای بخش‌ها

### امروز
اولین صفحه‌ای که هر روز می‌بینید:
کارهای امروز، کارهای عقب‌افتاده، سررسیدهای مالی، تاریخ‌های نزدیک و هفتهٔ پیش‌رو.
کادر بالای صفحه برای افزودن سریع کار است — بنویسید و Enter بزنید.

### کارها
- **تکرار:** هر روز، شنبه تا چهارشنبه، روزهای دلخواه هفته، ماهانه، سالانه، یا هر چند روز یک‌بار
- **ساعت و یادآوری:** می‌توانید ساعت بگذارید و بگویید چند دقیقه قبل خبرتان کند
- **اهمیت:** عادی / مهم / فوری
- کارهای تکرارشونده هر روز دوباره ظاهر می‌شوند و تیک هر روز جداگانه ثبت می‌شود

### گاوصندوق
برای هر مورد، قالب آماده وجود دارد:

| دسته | فیلدهای آماده |
|---|---|
| رمز و حساب | نام کاربری، رمز، نشانی سایت |
| کارت بانکی | نام بانک، شمارهٔ کارت، رمز دوم، رمز اول، انقضا، CVV2، شبا |
| حساب بانکی | شمارهٔ حساب، شبا، رمز اینترنت‌بانک |
| مدارک | کد ملی، شمارهٔ شناسنامه، تاریخ تولد |
| وای‌فای | نام شبکه و رمز |

می‌توانید هر فیلد دلخواه دیگری هم اضافه کنید. فیلدهای محرمانه پیش‌فرض پنهان‌اند و
با یک کلیک کپی می‌شوند (کپی بعد از ۴۵ ثانیه خودکار پاک می‌شود).
دکمهٔ ⚡ یک رمز قوی تصادفی می‌سازد.

### حساب و کتاب
- **بدهی و طلب:** برای هر نفر مبلغ و سررسید؛ پرداخت‌های جزئی هم ثبت می‌شود
- **اقساط:** مبلغ هر قسط و تعداد کل؛ با هر پرداخت، سررسید بعدی خودکار یک ماه شمسی جلو می‌رود
- **واریزها:** قبض، اجاره، شارژ و هر پرداخت دوره‌ای (ماهانه/سالانه)
- **گزارش ماهانه:** جمع پرداختی و دریافتی هر ماه شمسی، به تفکیک دسته

### تاریخ‌های مهم
تولدها، سررسید بیمه، چک و قرارداد. تکرار سالانه بر پایهٔ تقویم شمسی حساب می‌شود
و می‌توانید بگویید چند روز قبل یادآوری شود.

### پشتیبان‌گیری
از تنظیمات، یک فایل JSON از همهٔ اطلاعات می‌گیرید. اطلاعات گاوصندوق در این فایل هم
رمزشده‌اند. بازیابی هم از همان‌جا انجام می‌شود (ادغام یا جایگزینی کامل).

## یادآوری‌ها چطور کار می‌کنند؟

کلادفلر هر نیم‌ساعت یک‌بار برنامه را بیدار می‌کند و بررسی می‌کند:

- **خلاصهٔ روزانه:** هر روز در ساعتی که در تنظیمات انتخاب کرده‌اید (پیش‌فرض ۸ صبح)
- **کارهای ساعت‌دار:** سر وقت یا چند دقیقه قبل
- **سررسیدهای مالی:** روز سررسید قسط، بدهی یا واریز
- **تاریخ‌های مهم:** به اندازهٔ روزهایی که مشخص کرده‌اید، قبل از موعد

همهٔ ساعت‌ها به **وقت تهران** حساب می‌شوند.
اگر نوتیفیکیشن به گوشی نرسید، از تنظیمات دکمهٔ «ارسال آزمایشی» را بزنید.

## ساختار فنی

```
dastyar/
├─ wrangler.toml        تنظیمات استقرار (نام، پایگاه داده، زمان‌بند)
├─ schema.sql           ساختار جدول‌ها
├─ src/                 کد سمت سرور (Cloudflare Worker)
│  ├─ index.js          نقطهٔ ورود + زمان‌بند
│  ├─ api.js            مسیرهای API
│  ├─ auth.js           ورود و نشست
│  ├─ agenda.js         محاسبهٔ «برنامهٔ روز»
│  ├─ reminders.js      یادآوری‌های خودکار
│  ├─ push.js           ارسال نوتیفیکیشن (VAPID + aes128gcm)
│  └─ util.js           ابزارهای عمومی
├─ public/              برنامهٔ سمت مرورگر
│  ├─ index.html، sw.js، manifest.webmanifest
│  ├─ css/app.css
│  ├─ lib/              تقویم شمسی، تاریخ، منطق تکرار (مشترک با سرور)
│  └─ js/               هسته، اجزا، رمزنگاری و صفحه‌ها
└─ tools/               اسکریپت راه‌اندازی و ساخت آیکون
```

- بدون هیچ کتابخانهٔ بیرونی — نه در سرور، نه در مرورگر
- پایگاه داده: **Cloudflare D1** (SQLite)
- رمزگذاری: **AES-GCM 256** با کلید ساخته‌شده از رمز اصلی (PBKDF2، ۳۱۰٬۰۰۰ تکرار)
- نوتیفیکیشن: استاندارد Web Push، پیاده‌سازی مستقیم

### اجرا روی رایانهٔ خودتان (برای آزمایش)

```bash
npm run db:init:local
npm run dev
```

سپس نشانی http://127.0.0.1:8787 را باز کنید.

۱۰۰ هزار درخواست در روز، ۵ میلیون ردیف خواندن از پایگاه داده و زمان‌بند رایگان.
استفادهٔ شخصی هرگز به این سقف نمی‌رسد.
